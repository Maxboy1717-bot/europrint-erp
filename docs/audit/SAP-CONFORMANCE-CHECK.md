# SAP-Standards Conformance Check — EuroPrint ERP

**Date:** 2026-07-03
**Scope:** Backend (`apps/api/src`), DB schema (`lib/db/src/schema` + `apps/api/src/shared/db`), frontend contract points.
**Method:** Read-only code + schema investigation (5 parallel auditors). No code was modified, no migrations run, no commits made.
**Caveat:** The live database is essentially empty (build phase). This is a **code-level** conformance audit — the *logic* is evaluated, not production data volumes. Where a principle depends on data that is not yet seeded, that is stated explicitly.

No principle is fully absent. The dominant pattern is **"logic built, wiring or data incomplete"**: the engines (GL double-entry, 3-way match, FIFO, approval-chain traversal, config tables, audit interceptor) are genuinely implemented, but several are not connected end-to-end, or depend on master data (`head_user_id`, batch costs) not yet seeded.

## Highest-leverage fixes (ranked)

1. **Approval chain (#7)** — seed `org_departments.head_user_id` for the ~30 departments and enable the disabled `manager_id` backfill. This is *owner data*, not code; the traversal already works. Unblocks all document approval + SLA escalation.
2. **POS → canonical GL (#3, #9)** — add the `pos_gl_postings` → `entries` promotion bridge so POS/cashier movements become real double-entry rows. Two GL worlds today.
3. **Vendor payment + MM goods-receipt GL posting (#3)** — wire `postVendorPayment` and `postGoodsReceipt` (both defined, zero callers).
4. **Payment-side three-way-match gate (#5)** — enforce match status before releasing vendor payment, not only at goods-receipt.
5. **QC→WMS FG hop (#4, #9)** — make the failure-swallowing listener surface errors; add a real order↔QC FK instead of event-payload-only attribution.
6. **Master-data unification (#1)** — pick one canonical product/material table and FK the others; collapse the 3 conflicting `sales_orders` Drizzle definitions to the live integer-PK shape.
7. **`updated_by` population (#8)** — set the actor on WMS stock and workflow_rules update paths (columns exist, code doesn't write them).
8. **Config the hardcoded bits (#6)** — move `HitlDocumentType` + `HITL_THRESHOLDS` into `document_types` / threshold config tables.
9. **Zero-listener events (#9)** — either add consumers for the 5 AI-agent alerts + payroll/security events, or remove the dead emits; fix the `pos.requisition.*` vs `pos.request.*` namespace split.
