### Breaks (drift / missing FK / two-worlds / green-lie / orphan)

- **GREEN-LIE: crm-ai-extended.controller.ts:137-141** — `POST /crm/ai/nba/create-task` returns `{ created: true, taskId: Date.now() }` with no INSERT into crm_tasks or any other table. FE (AIAnalysisPanel.tsx:59) calls this and expects a task to be created.

- **GREEN-LIE: crm-extras.service.ts:69-78** — `getNba()` returns a hardcoded 3-item recommendations array (`follow_up_call`, `send_proposal`, `schedule_demo`) without any DB query. Route `GET /crm/nba` always returns the same static data regardless of entity.

- **THREE-WORLDS LEAD SPLIT**: Business concept "lead" lives in 3 separate tables with no FK bridge:
  - `crm_leads` (id=integer): CRM-core, 5 rows, written by 3 different repos. THE canonical writer.
  - `leads` (id=uuid): 0 rows, zero writers in code. TRUE ORPHAN table.
  - `marketing_leads` (id=varchar): 0 rows, has `crm_lead_id` FK column pointing to `crm_leads.id` but no backend writer creates rows here. FE MarketingLeads.tsx:117 calls `POST /api/marketing/leads/:id/convert-to-crm` but no matching BE controller handles this path.

- **DRIFT: FE calls `/api/crm/ai/supervisor-dashboard`** (ExtendedAIPanel.tsx:162) but BE has it at `/api/crm/supervisor-dashboard` (CrmAutoLeadController, `@Controller('crm')` + `@Get('supervisor-dashboard')`). Path mismatch — 404 in production.

- **DRIFT: FE calls `/api/ai/crm/score-lead/:leadId`**, `/api/ai/crm/deal-probability/:dealId`**, `/api/ai/crm/churn-risk/:contactId`**, `/api/ai/crm/email-template`**, `/api/ai/crm/next-best-action/:dealId`** (lib/api/ai.ts:16-24) — no matching BE routes exist at these paths. These routes belong to an `/ai/crm/*` namespace that has no controller.

- **DRIFT: FE calls `PATCH /api/crm/deals/close`** (CrmFunnelAnalytics.tsx:215) — no BE route handles `/crm/deals/close`. Only `/crm/deals/:id/won` exists.

- **DUPLICATE ROUTE: `POST /crm/leads/quick` vs `POST /crm/leads`** — both are defined in crm-leads.controller.ts (lines 148 and 198) and do identical work. The "quick" variant is a pure alias.

- **DUPLICATE ROUTE: `POST /crm-bitrix/robots/:id/toggle` and `PATCH /crm-bitrix/robots/:id/toggle`** — both defined in crm-bitrix-compat.controller.ts (lines 91 and 110), same handler body.

- **SD leads two-world read**: `SdLeadsController` (`/sd/leads`) has no `sd_leads` table — it reads/writes `crm_leads` directly. The SD module uses `crm_leads` as its lead store; there is no separate `sd_leads` table in the live DB.

- **sd-leads.controller.ts:107** — `assertRequired(body.full_name, 'full_name required')` but the INSERT statement (sd-leads.repository.ts:89) uses `body.title` not `body.full_name`. The SdCreateLeadSchema field mapping may silently fail if FE sends `full_name` without a `title` field.

- **crm_lead_stages has 0 rows and no seed data**: `GET /crm/lead-stages` returns empty array. FE uses static fallback stages in the kanban board, so this is not runtime-breaking but the CRM pipeline stage management UI shows nothing.

- **comms routes are log-only with no real provider**: `POST /crm/email/send`, `/crm/sms/send`, `/crm/whatsapp/send` log activity rows to `crm_activities` but do NOT actually send any message. Response body claims `{ sent: true }` — technically a partial green-lie (persists, but the key promise "sent" is false).

### Vision link (which of 22 visions this serves, % built)

Serves **Vision 3 — CRM/Sales pipeline** (lead capture → qualify → convert to deal → close). CRM core routes are approximately **65% built**: all CRUD for leads, deals, contacts, companies, activities, and the lead-to-deal conversion command are real and functional. Gaps: `nba/create-task` is a stub, 5 FE `/api/ai/crm/*` paths have no BE handler, `leads` table is an orphan, `crm_lead_stages` has no data, and comms channels (`email/sms/whatsapp`) log activities but do not actually deliver messages.

### 3-line summary

CRM core is the most complete module in the system: ~115 routes, all major CRUD (leads/deals/contacts/companies/activities) backed by real Drizzle or raw-SQL writes into canonical tables (`crm_leads` 5 rows, `crm_activities` 3 rows, `crm_tasks` 5 rows). Two confirmed green-lies (`nba/create-task` returns `Date.now()` id, `getNba` returns hardcoded list) and 5 unreachable FE paths (`/api/ai/crm/*`).
