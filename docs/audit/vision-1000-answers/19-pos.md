5. FIFO: `pos_movement_items` jadvalida `batch_id` + `received_at` bo'yicha eng eski partiya avval ketadi; rulon qoldig'i nolga tushsa keyingi `batch_id`ga avto o'tadi; GL yozuv har batch uchun o'sha batch kirim narxi (FIFO) bilan hisoblanadi; qisman rulon uchun og'irlik proporsional taqsimlanadi.
6. `material_cards.expiry_tracked=true` → FEFO (muddati yaqinrog'i avval); `false` → FIFO; `pos_movements.dispatch()` funksiyasida `ORDER BY CASE WHEN expiry_tracked THEN expiry_date ELSE received_at END`; muddati o'tgan material chiqimda TO'LIQ BLOKLANADI (faqat ogohlantirish emas) — shart `material_cards` + `stocks.expiry_date < NOW()`.

10.
