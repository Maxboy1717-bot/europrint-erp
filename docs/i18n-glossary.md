## 5. Punctuation & typography rules

- **Quotes in UZ**: use `"…"` (straight ASCII) for ERP UI; `«…»` for documents.
- **Quotes in RU**: use `«…»` always.
- **Apostrophes in UZ**: use `'` (single straight) for `o'`, `g'`, `sh'`.
- **Dash**: `—` (em dash) for both languages.
- **Numbers**: thousand separator = space (`1 234 567`). Decimal = `.` (period).
- **Currency**: `1 234 567 so'm` (UZ) / `1 234 567 сум` (RU).
- **Date format**: `DD.MM.YYYY` for both languages.
- **Time format**: `HH:mm` (24-hour).

## 6. Variable interpolation

i18n keys MUST preserve `{var}` placeholders verbatim. Translators rephrase
around them, never alter them.

```
✅ "{count} buyurtma topildi"   → "Найдено {count} заказов"
❌ "{count} buyurtma topildi"   → "Найдено {колво} заказов"  ← WRONG
```

When pluralisation matters, use ICU select form:
```json
{
  "ordersFound": "{count, plural, =0 {Buyurtma topilmadi} one {# buyurtma topildi} other {# ta buyurtma topildi}}"
}
```

## 7. Tone & style

- **Address form**: 2nd person plural ("siz" in UZ, "вы" in RU).
- **Avoid passive constructions** when active is natural.
- **Buttons & menu items**: imperative ("Saqlash", "Сохранить" — NOT "Saqlamoq" / "Сохранение").
- **Confirmation messages**: past tense ("Saqlandi" / "Сохранено").
- **Errors**: factual, no exclamation marks, no emoji.

## 9. How to use this glossary

1. **Before adding a new key**: check sections 2–4 for an existing translation.
2. **When translating a string**: prefer the canonical form from this glossary,
   even if word-for-word a different word exists.
3. **When proposing a new term**: add it here first, then use it everywhere.
4. **Conflicts**: this glossary wins. Existing keys that disagree must be
   migrated.
